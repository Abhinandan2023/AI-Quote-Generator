# AI Quote Generator using LSTM

A category-conditioned quote generation application built using TensorFlow, LSTM and Streamlit.

## Features

- Generate quotes based on category
- Control maximum quote length
- LSTM-based text generation
- Streamlit web interface
- Temperature sampling
- Repetition penalty

## Technologies

- Python
- TensorFlow / Keras
- LSTM
- NumPy
- Streamlit
